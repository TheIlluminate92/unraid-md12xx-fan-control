# Acknowledgements and development transparency

This is an AI-assisted open-source project. The roles are documented plainly so users can make an informed decision about the software they install:

- **Erik Boettcher / TheIlluminate92** — project owner; product direction; original Docker prototype; MD1200 hardware access; safety decisions; destructive testing; repeated commissioning validation; and release approval.
- **OpenAI Codex (GPT-5)** — primary implementation assistance, including architecture, code generation, tests, documentation, packaging, and debugging, under Erik's direction and review.
- **The Unraid community** — plugin conventions, field reports, and the operators who documented practical Dell PowerVault and BlueDress console behavior over the years.
- **Beta testers** — especially anyone validating MD1220 hardware, alternate HBAs, firmware revisions, and USB serial adapters. Hardware reports directly improve the plugin's fail-safe detection rules.

AI assistance does not replace operator review or hardware validation. Releases are approved by the project owner after automated checks and, where available, controlled hardware testing.
